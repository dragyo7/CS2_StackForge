# StackForge Documentation Pack

This folder contains the product and engineering specification for StackForge.

Read `Userflow.md`, `Rules.md`, then `docs/HANDOVER.md`.

**Critical product rule:** maps are random. There is no map picker or map veto. Map-specific performance is used privately to make team splits robust across the active map pool.

See `docs/INTEGRATIONS.md` for the external-source registry and use/limitations.
